# JS Execution Visualizer

## Purpose
JS Execution Visualizer is a web-based tool designed to help users understand how JavaScript code executes step-by-step. It provides a visual representation of the execution flow, making it easier for learners and developers to grasp concepts such as variable scope, function calls, and the call stack.

## Features
- Visualize JavaScript code execution in real-time
- Step through code to observe changes in variables and the call stack
- User-friendly interface for both beginners and experienced developers

## Intention
The intention behind creating this project is to provide an educational resource for those learning JavaScript or seeking to deepen their understanding of how JavaScript code runs under the hood. By making the execution process visible, users can debug, experiment, and learn more effectively.

## Usage
1. Open `index.html` in your browser.
2. Enter or load JavaScript code.
3. Use the controls to step through the code and observe the execution flow.
